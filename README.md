# Aare Renu Shri — Portfolio

Personal portfolio website — live at [aarenushri.github.io/aare-renu-shri-portfolio](https://aarenushri.github.io/aare-renu-shri-portfolio/)

A minimal, type-driven single-page portfolio built with React and Vite, featuring an editorial photo collage, an interactive project explorer, and a contact section.

## Tech

- [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [lucide-react](https://lucide.dev/) + [simple-icons](https://simpleicons.org/) for icons

## Sections

1. **Hero** — name over giant display type
2. **About** — intro, portrait, social links
3. **Skills & Courses** — tech stack and core coursework
4. **Projects** — click-to-open folders with tech stickers
5. **PORs & Extracurricular** — positions of responsibility and event collage
6. **Contact** — email, phone, socials, and CV

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Every push to `main` auto-deploys the site to GitHub Pages via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
